# AI Course Information

Release: 1.0.58  
Numeric version: 2026110602

## Summary
AI Course Information creates structured learner-facing course information from course details and activities.

## Description
Teachers can generate and review a course guide with outcomes, delivery details, assessment information, learner support and other course requirements. The module also supports AI Course Builder: it receives the teacher's learning outcomes and teaching context for the current course unit. The established standalone and VET workflows remain unchanged.

## Features
- Build a structured course information document from course details and activities.
- Present course outcomes and learning requirements in one learner-facing guide.
- Store learner acknowledgement with its audit details.
- Use unit-specific teacher outcomes when generated by AI Course Builder.

## Requirements
- Moodle 4.0 or later, with the `mod_courseinfo` activity installed.

## Installation
- Install the exact `mod_courseinfo` release ZIP through Moodle's plugin installation page.
